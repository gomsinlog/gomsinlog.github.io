1. 개인정보처리자와 방침의 범위

  • 개인정보처리자는 한예성입니다. 이 방침은 곰신로그 모바일 앱의 개인정보 처리에 적용됩니다.
  • 이 방침은 2026-09-27부터 시행합니다. 이후 변경은 12항에 따라 안내합니다.

2. 처리 항목·목적·보유기간

  • 계정(필수): 이메일 주소(Apple 로그인에서 이메일 가리기를 선택하면 Apple이 제공하는 중계 주소), 인증 제공자(Apple 또는 Google), 인증용 계정 식별자 — 로그인, 계정 보안, 문의 대응 — 회원 탈퇴 시까지
  • Apple 로그인 토큰(Apple 로그인 사용 시): Apple이 발급한 갱신 토큰을 서버에 암호화해 저장합니다 — 탈퇴 시 Apple에 토큰 폐기를 요청하기 위해 — 탈퇴 시 폐기를 요청하며, 즉시 완료되지 않으면 폐기가 확인될 때까지 자동으로 다시 시도하고 그동안 암호화된 상태로 보관합니다.
  • 프로필(필수): 닉네임, 관계 유형(군 복무/일반), 서비스 내부 멤버 구분값, 커플 연결 식별자 — 관계에 맞는 화면과 1:1 공간 제공 — 회원 탈퇴 또는 연결 해제 시까지
  • 관계·복무(선택): 사귄 날짜, 연락 가능 시간 및 군 복무 커플이 입력한 군종, 복무 상태, 입대일, 예상 전역일 — 일정·디데이 표시 — 이용자가 삭제·수정하거나 회원 탈퇴 시까지
  • 기록(선택): 제목·본문, 날짜·시간, 리액션, 공유 범위와 첨부 참조 — 기록 저장과 이용자가 선택한 상대방 공유 — 이용자의 삭제 요청 또는 계정 삭제 처리에 따름
  • 일정 데이터(계정에 저장된 경우): 제목, 유형, 날짜, 공개 범위와 작성 정보 — 저장된 항목 처리 — 이용자의 삭제 요청 또는 계정 삭제 처리에 따름
  • 사진(선택): 사용자가 첨부한 사진과 파일명·종류·저장 참조 — 기록 첨부와 사용자가 선택한 상대방에게 표시 — 해당 기록 또는 계정의 삭제 처리에 따름. 새 사진은 업로드 전에 변환되며 사진 바이트 자체는 종단간 암호화되지 않습니다.
  • 주기 정보(선택·민감 가능): 주기 원본(시작·종료일, 일별 컨디션·증상·메모, 평균 주기 설정)은 서버에 저장되며 앱에서는 본인 계정만 열람할 수 있습니다(운영 접근 범위는 11항 참고). 주기 공유를 켜면 실제·예상 기간 날짜만 상대방에게 제공되며 증상과 메모는 제공하지 않습니다.
  • 복무패스 구매 기록(구매 시): 거래 ID·원거래 ID, 상품, 구매·환불 일시, 거래 상태, 결제 환경과 계정 연결을 위한 해시값 — 구매 확인, 이용 권한 부여, 환불 반영, 분쟁 대응 — 구매 기록은 거래 기록 보관 의무를 위해 계정 삭제 후에도 보관합니다. 카드 번호 등 결제수단 정보는 Apple이 처리하며 운영자는 받지 않습니다.
  • 하루 요약(선택): iPhone 기기 안의 Apple Foundation Models로 만듭니다. 요약을 위해 기록 글을 서버나 외부 AI 서비스로 보내지 않습니다.
  • 푸시 알림(허용 시): 기기 알림 토큰 — 새 소식 알림 전송 — 알림을 끄거나 계정 삭제 시까지. 알림 내용은 고정 문구뿐이며 기록 내용이나 이름을 담지 않습니다.
  • 자동 생성 정보: 접속 시각, IP 주소, 기기·OS·앱 버전, 인증·보안·오류 로그 — 장애 대응과 보안 — 실제 제공업체의 로그 보유 정책에 따르며 정확한 기간은 배포 설정 확인이 필요합니다.
  • 현재 확인 가능한 앱 경로에서 주소록·통화·문자 내역을 요청하지 않습니다. 처리 항목은 실제 배포된 앱과 제공업체 설정을 기준으로 공개 전에 다시 확인합니다.

3. 수집 방법과 처리 근거

  • 이용자가 로그인, 온보딩, 기록 작성, 현재 제공되는 설정과 파일 선택 과정에서 직접 입력·선택한 정보를 처리합니다. 접속·보안 로그는 서비스 이용 중 인프라에서 자동 생성될 수 있습니다. 현재 서비스는 여행 계획과 지도 OCR을 제공하지 않습니다.
  • 계정·프로필과 이용자가 요청한 핵심 기능은 서비스 이용계약의 체결·이행을 위해 처리합니다. 선택 기능은 이용자의 요청 또는 동의를 근거로 처리하며 선택하지 않아도 해당 선택 기능 외의 서비스 이용은 제한하지 않습니다.
  • 주기·증상처럼 건강 관련 민감정보에 해당할 수 있는 정보는 별도 고지와 명시적 동의를 거쳐야 하며, 이용자는 언제든지 입력을 중단하고 기존 정보를 삭제할 수 있습니다.

4. 연결된 상대방에게 제공되는 정보

  • 제공받는 자는 초대 코드로 연결된 상대방 1명이며, 목적은 이용자가 선택한 기록과 현재 제공되는 공유 기능을 제공하는 것입니다.
  • 공유 범위를 선택한 기록, 리액션, 공유용 프로필과 군 복무 커플이 선택한 복무 디데이가 제공될 수 있습니다. 일정 데이터가 상대방에게 공유되는 경우 작성자가 선택한 항목만 제공됩니다. “나만 보기” 기록과 본인 전용 주기 원자료·증상·메모는 상대방에게 제공하지 않습니다.
  • 주기 공유는 켜기/끄기 하나입니다. 이용자가 주기 공유를 켜면 실제·예상 기간 날짜만 상대방 달력에 색으로 표시됩니다. 증상과 개인 메모는 공유 대상이 아니며, 끄면 상대방에게 더 이상 표시되지 않습니다.
  • 연결을 해제하면 상대방의 서버상 접근 권한은 즉시 종료됩니다. 이용자는 공유를 원하지 않으면 나만 보기를 선택하거나 연결을 해제할 수 있습니다.

5. 처리 위탁과 국외 처리

  • Supabase Inc.: 인증, 데이터베이스, 실시간 동기화, 비공개 파일 저장과 백엔드 기능(서버 함수) 운영. 계정·프로필·기록·일정·미디어와 접속 로그가 암호화된 통신으로 서비스 이용 시 전송되며, 프로젝트가 설정된 데이터 처리 지역과 Supabase의 보조처리자에서 계정 또는 데이터 삭제 시까지 처리될 수 있습니다.
  • Apple Inc.: Apple 로그인을 선택한 경우 인증, 복무패스의 앱 내 결제·환불 처리, 푸시 알림 전송(APNs)을 수행합니다. 결제는 Apple이 직접 처리하며 운영자는 결제수단 정보를 받지 않습니다. 푸시 알림에는 고정 문구만 담습니다.
  • Google LLC: Google 로그인을 선택한 경우 인증을 수행합니다.
  • 외부 제공업체의 실제 처리 국가와 재수탁자 목록은 서비스 설정에 따라 달라질 수 있습니다. 운영자는 이용 전에 해당 국가와 재수탁자를 이 방침에 구체적으로 안내합니다. 국외 처리에 동의하지 않으면 해당 외부 인프라를 사용하는 서비스 이용이 어려울 수 있습니다.

6. 기기 내 임시 저장

  • 전송 대기 중인 기록과 파일은 기기의 IndexedDB에 일시 보관될 수 있습니다. 계정별로 격리되며, 서버 전송이 확인되기 전에는 기록이 서버에 저장되었다고 간주하지 마세요. 앱 삭제·로그아웃 전에 화면의 전송 상태를 확인해야 합니다.

7. 사진과 첨부 정보

  • 현재 첨부 업로드는 사진을 대상으로 하며 음성 녹음과 여행 OCR 기능은 제공하지 않습니다. 계정에 과거 형식의 영상·음성 첨부가 이미 연결되어 있다면 일부 화면에서 표시될 수 있습니다. 해당 자료의 현재 보유 여부와 정리 상태는 별도로 확인해야 합니다.
  • 사진은 업로드 전에 새 이미지로 다시 만들어 EXIF 위치정보를 제거합니다. 사진은 AVIF(변환이 안 되면 JPEG)로, 목록용 작은 사진은 JPEG로 저장합니다. 앱은 사진에서 보이는 배경·표지판·시설 정보까지 지우지 않으므로 부대·정확한 위치가 드러나지 않는지 직접 확인해야 합니다.

8. 파기 절차와 계정 삭제

  • 계정 삭제 요청은 앱과 서버의 여러 단계를 거칩니다. 계정 접근 종료 뒤에도 사진 파일 정리는 별도 후속 작업으로 진행됩니다. 처리가 중단되어 복구 화면이 나오면 완료로 간주하지 말고 화면의 재시도 절차를 따라야 합니다. 기기 내 대기 자료의 정리도 별도 단계일 수 있습니다.
  • 서비스는 전체 서버 시점 스냅샷이나 자동 복원을 제공한다고 보장하지 않습니다. 운영상 별도 사본의 생성 여부와 보유·파기 기간은 모든 제공업체에 대해 확정되어 있지 않습니다. 삭제 요청이 사용자 기기나 상대방의 다운로드 사본까지 지우지는 않습니다.
  • iPhone 전체 ZIP은 여러 평문 파일로 전달되며 항목별 실패가 있을 수 있습니다. 상대방이 직접 작성한 콘텐츠는 상대방 계정에 남습니다.

9. 이용자의 권리와 행사 방법

  • 이용자는 자신의 개인정보 열람, 정정·삭제, 처리정지, 동의 철회와 내보내기를 요구할 수 있습니다. 설정 화면에서 가능한 요청을 직접 수행할 수 있으며, 내보내기는 iPhone 앱의 전체 ZIP으로 제공합니다.
  • 앱에서 처리하기 어려운 요청은 아래 개인정보 문의처로 접수할 수 있습니다. 운영자는 본인 확인 후 관련 법령이 정한 기간 안에 처리 결과 또는 제한 사유를 알립니다.
  • 개인정보 침해 상담은 개인정보침해신고센터(국번 없이 118), 개인정보분쟁조정위원회(1833-6972), 경찰청(국번 없이 182) 등에도 요청할 수 있습니다.

10. 만 14세 미만 아동

  • 서비스는 만 14세 미만 아동을 대상으로 하지 않으며 현재 법정대리인 동의 확인 절차를 제공하지 않습니다. 따라서 만 14세 미만은 가입하거나 서비스를 이용할 수 없습니다.
  • 만 14세 미만의 정보가 동의 확인 없이 수집된 사실을 알게 되면 해당 계정과 정보를 확인 후 지체 없이 삭제합니다.

11. 안전성 확보조치와 암호화 범위

  • 인증된 통신, 데이터베이스 행 단위 권한(RLS), 비공개 파일 저장소, 권한 확인과 계정·커플 범위 분리를 적용하는 경로가 있습니다. 이런 조치가 모든 데이터에 종단간 암호화를 적용한다는 뜻은 아닙니다.
  • 새 기록의 글 내용은 서버에 저장됩니다. 인증된 사용자에게 계정과 연결 상태에 따른 접근 권한을 적용합니다. 기존 기기 보호 형식의 기록은 이 버전에서 열 수 없을 수 있으며, 새 기록에 종단간 암호화가 적용된다고 안내하지 않습니다.
  • 사진 파일은 비공개 저장소와 접근 권한으로 보호하지만 종단간 암호화되지 않습니다.
  • 기록의 글·사진과 주기 정보(민감 가능 정보 포함)는 서버가 읽을 수 있는 형태로 저장됩니다. 앱에서는 본인과 공개 범위에 따른 상대만 볼 수 있지만, 제한된 운영 권한으로 장애·보안 대응이나 법적 의무 이행에 필요한 범위에서 접근이 가능할 수 있습니다.

12. 개인정보 보호책임과 방침 변경

  • 한예성가 개인정보 보호 업무와 이용자 요청 처리를 담당합니다. 문의처는 아래에 표시됩니다.
  • 수집 항목, 이용 목적, 제3자 제공, 국외 처리 또는 보유기간이 실질적으로 변경되면 시행일과 변경 사항을 먼저 안내하고, 법령상 필요한 경우 별도 동의를 받습니다. 계정별 보유기간, 운영 백업의 파기 기간과 배포 국가·재수탁자 목록은 공개 전에 확정해야 합니다.
