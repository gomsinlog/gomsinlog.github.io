개인정보 처리방침

수집하는 개인정보 없음

북스튜디오(v1.0 단독 출시 기준)는 회원가입이나 로그인 없이 iPad 안에서만 동작합니다. 책 내용, 사진, 캡처 이미지, 기록 원문을 개발자 서버나 외부 서비스로 전송하지 않습니다.

1. 로컬 iPad 전용 저장 및 비수집 원칙

사용자가 만든 책(.bookstudio), 가져온 사진, 직접 작성한 글, 손글씨, 자료함 기록은 모두 사용자의 iPad 내부 저장소에만 보관됩니다.

  • 사진 접근: 시스템 사진 선택기(PHPickerViewController)와 붙여넣기만 사용하므로 사진 보관함 전체 접근 권한을 요구하지 않습니다.
  • 추적·광고 없음: 광고 SDK, 행동 분석 도구, 추적 식별자(IDFA 등)를 포함하지 않습니다.

2. 기기 내(온디바이스) 처리 기능

북스튜디오의 글 읽기 및 문장 선별 기능은 100% iPad 기기 안에서만 실행됩니다.

  • 사진 속 글·대화 읽기 (Apple Vision): 사용자가 캡처 이미지에서 글 읽기를 실행하면 Apple의 기기 내 문자 인식(Apple Vision)만 사용해 텍스트를 추출합니다. 이미지와 추출된 글은 기기 밖으로 전송되지 않습니다.
  • 원문 한 줄 선별 (BookQuoteRanker.bundle): 책에 담긴 기록에서 문장을 골라 보여 줄 때 앱에 내장된 온디바이스 구성 요소(BookQuoteRanker.bundle)만 iPad 안에서 동작합니다. 기록 텍스트는 외부 서버로 0바이트도 전송되지 않으며 새 문장을 만들어 내지 않고 작성한 원문 그대로만 표시합니다.

3. 파일 가져오기·내보내기 및 기기 백업

  • 기록 파일 및 PDF 전달: 파일 앱, AirDrop, 공유 시트로 .gomsinbook 기록 파일을 열거나 완성한 A5 PDF를 저장·공유하는 동작은 사용자가 직접 시작하는 기기 내 전달이며 개발자 서버를 거치지 않습니다.
  • 기기 백업: 앱 내부에 저장된 책의 백업 여부는 사용자가 설정한 iPad의 iCloud 백업 또는 Mac 백업 설정을 따릅니다. 편집 중인 작업용 임시 파일은 시스템 백업 대상에서 제외됩니다.
  • 외부 저장 사본: 파일 앱에 따로 저장하거나 다른 앱으로 공유한 PDF 사본은 북스튜디오 앱과 별개로 관리됩니다.

4. 향후 선택적 iCloud 및 계정(BookAccount) 기능 경계

현재 단독 출시 버전(v1.0)은 오프라인 전용입니다. 서버 동기화, 클라우드 보관, 로그인 화면을 제공하지 않으며 네트워크 계정 모듈이 비활성 상태로 잠겨 있습니다.

추후 업데이트에서 선택적 iCloud 연동이나 곰신로그 계정 연결(BookAccount) 기능을 제공하게 되면 기능을 열기 전에 이 개인정보 처리방침과 App Store 개인정보 라벨을 실제 처리 항목에 맞게 먼저 갱신하고 사용자 동의를 받습니다.

5. 앱 내 데이터 삭제 방법

  • 개별 책 영구 삭제: 앱 내 책장에서 책 카드의 더보기(···) 메뉴를 열고 휴지통으로 이동을 선택합니다. 이후 휴지통에서 해당 책의 완전히 삭제를 눌러 2단계 확인(삭제 대상 확인 → 최종 삭제 확인)을 마치면 책 문서와 앱 안에 보관된 PDF가 이 iPad에서 영구 삭제됩니다.
  • 외부 사본 유지 범위: 이미 외부에 공유하거나 파일 앱에 따로 저장한 PDF 사본과 곰신로그 원본 기록은 북스튜디오에서 책을 삭제해도 지워지지 않습니다.
  • 전체 데이터 삭제: iPad 홈 화면이나 설정에서 북스튜디오 앱을 삭제하면 앱 내부에 저장된 모든 책과 자료가 함께 지워집니다.

6. 오픈소스 고지 및 웹 페이지 접속 정보

앱 내 설정 → 오픈소스 라이선스 화면에서 포함된 글꼴, ZIPFoundation, BookQuoteRanker.bundle 구성 요소의 라이선스 전문을 확인할 수 있습니다.

앱 설정의 개인정보 처리방침 및 지원 문의 링크는 시스템 브라우저(Safari)로 이 정적 웹 페이지를 열며 앱 데이터를 함께 전달하지 않습니다. 정적 웹 페이지 호스팅(GitHub Pages) 과정에서 호스팅 제공자가 보안·운영 목적의 표준 웹 접속 기록을 처리할 수 있습니다.
